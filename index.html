One pipeline, three phases

Every funded training program goes through the same administrative lifecycle. I automated each phase end-to-end.

Phase 1

Program Launch

Enrollment files, adhesion letters, apprenticeship quotes and financial plans — prepared in minutes instead of days, straight from raw data.

Phase 2

Delivery

While the course runs: attendance registers filled automatically, e-learning hours tracked with excess-time detection, tutoring hours distributed within regulatory constraints.

Phase 3

Reporting

When it ends: certificates generated per participant and sorted per company, transparency documents and project timesheets compiled automatically.

About this portfolio

I work in the administration of funded vocational training programs. Every tool on this page was built to solve a real, recurring problem in my daily work — not as an exercise.

The result: manual processes that used to take hours now run in seconds, with consistent output that can be verified and audited. The tools operate on Word, Excel and PDF files, which is where training administration actually lives.

All tools run locally, process personal data responsibly and never modify the original files they work on.

  • Source files are sacredEvery tool works on copies; originals are never modified, and inputs are archived after processing.
  • Robustness against messy dataTruncated names, typos, Italian number formats and broken exports are handled by design, not by luck.
  • Usable by anyoneThe most-used tools ship with double-click launchers, so colleagues without technical skills can run them.
  • Iterated in the fieldThe e-learning monitor reached version 17 through real-world feedback — each version fixing an actual edge case.
